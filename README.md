# 🎭 Who Am I? - เกมทายตัวตน

เกมบอร์ดออนไลน์แบบ Multiplayer สำหรับเล่นกับเพื่อนใน LAN/WiFi เดียวกัน ผู้เล่นแต่ละคนจะได้รับคำที่ตัวเองไม่รู้ แต่คนอื่นจะเห็น และต้องทายว่าตัวเองคือคำอะไร!

## 📋 รายละเอียดโปรเจค

- **Framework**: Next.js 16 + React 19
- **Styling**: Tailwind CSS 4
- **Real-time**: Socket.io
- **Language**: TypeScript

โปรเจคนี้ออกแบบมาให้รันบนเครื่อง Host และให้ผู้เล่นคนอื่นเข้าร่วมผ่าน URL ใน WiFi เดียวกัน

---

## 🚀 วิธีการติดตั้ง

### ความต้องการ
- Node.js 18+
- pnpm (แนะนำ) หรือ npm/yarn

### ขั้นตอน

1. **Clone โปรเจค**
```bash
git clone <repository-url>
cd board-game-who-am-i
```

2. **ติดตั้ง Dependencies**
```bash
pnpm install
# หรือ
npm install
```

3. **รัน Development Server**
```bash
pnpm dev
# หรือ
npm run dev
```

4. **Build สำหรับ Production**
```bash
pnpm build
pnpm start
```

## 🎮 วิธีการใช้งาน

### สำหรับ Host (คนเปิดเกม)

1. รัน `pnpm dev` บนเครื่องของคุณ
2. เปิดเบราว์เซอร์ไปที่ `http://localhost:3000`
3. กด **"สร้างห้องใหม่"**
4. ใส่ชื่อห้อง, รหัสผ่าน (ถ้าต้องการ), และชื่อของคุณ
5. แชร์ URL ให้เพื่อน (เช่น `http://192.168.x.x:3000`) - ต้องอยู่ WiFi เดียวกัน
6. รอผู้เล่นเข้าห้อง แล้วกดเริ่มเกม!

### สำหรับผู้เล่นอื่น

1. เปิดเบราว์เซอร์ไปที่ URL ที่ Host แชร์มา (ต้องอยู่ WiFi เดียวกัน)
2. เลือกห้องที่ต้องการเข้าร่วม
3. ใส่ชื่อของคุณ (และรหัสผ่านถ้าห้องต้องการ)
4. รอ Host เริ่มเกม!

### วิธีเล่น

1. เมื่อเกมเริ่ม ทุกคนจะได้รับคำจากหมวดหมู่ที่เลือก
2. **คุณจะไม่เห็นคำของตัวเอง** แต่จะเห็นคำของคนอื่น
3. ถามคำถามเพื่อทายว่าตัวเองคืออะไร (ตอบแบบปากเปล่า)
4. Host จะกดให้คะแนนเมื่อคุณตอบถูก
5. คะแนน: อันดับ 1 = 3 คะแนน, อันดับ 2 = 2 คะแนน, อันดับ 3 = 1 คะแนน

## ➕ วิธีการเพิ่ม Category

แก้ไขไฟล์ `src/constant/index.ts`

### 1. เพิ่มชื่อ Category ใน `CATEGORY_LIST`

```typescript
export const CATEGORY_LIST = [
  "สัตว์บก",
  "ผลไม้",
  // ... categories อื่นๆ
  "หมวดหมู่ใหม่ของคุณ",  // เพิ่มตรงนี้
];
```

### 2. เพิ่มคำในหมวดหมู่ใน `PRESET_CATEGORIES`

```typescript
export const PRESET_CATEGORIES = [
  // ... categories อื่นๆ
  {
    name: "หมวดหมู่ใหม่ของคุณ",  // ต้องตรงกับใน CATEGORY_LIST
    words: [
      "คำที่ 1",
      "คำที่ 2",
      "คำที่ 3",
      // เพิ่มคำอย่างน้อย 10-20 คำเพื่อความหลากหลาย
    ],
  },
];
```

## 📝 วิธีการเพิ่มคำในหมวดหมู่ที่มีอยู่แล้ว

1. เปิดไฟล์ `src/constant/index.ts`
2. หา `PRESET_CATEGORIES`
3. หาหมวดหมู่ที่ต้องการเพิ่มคำ
4. เพิ่มคำใน array `words`

**ตัวอย่าง**: เพิ่มคำในหมวด "สัตว์บก"

```typescript
{
  name: "สัตว์บก",
  words: [
    "สุนัข",
    "แมว",
    "ช้าง",
    // ... คำที่มีอยู่
    "หมาป่า",      // เพิ่มคำใหม่
    "จิงโจ้",      // เพิ่มคำใหม่
  ],
},
```

> 💡 **เคล็ดลับ**: ควรมีคำอย่างน้อย 10-20 คำต่อหมวดหมู่ เพื่อไม่ให้ซ้ำกันบ่อยเกินไป
